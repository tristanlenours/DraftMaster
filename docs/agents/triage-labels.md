# Triage Labels

Use these canonical workflow roles exactly as written.

| Role | GitHub label | Meaning |
| --- | --- | --- |
| Unreviewed | `needs-triage` | A maintainer must qualify the request. |
| Waiting for facts | `needs-info` | Required information is missing. |
| Agent-ready | `ready-for-agent` | Scope and acceptance criteria support autonomous work. |
| Human-required | `ready-for-human` | A human decision or action is required. |
| Declined | `wontfix` | The request was consciously excluded. |

Move an issue to one actionable role at a time; remove stale role labels when its state changes.
