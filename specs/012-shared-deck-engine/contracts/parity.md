# Parity contract

Equal card facts and evaluation options produce equal axes, scores and evidence across journeys; instance ids are compared through card names/oracle identity. Equal pool order and options produce equal deterministic proposals, independent of import/draft origin. Caller-specific validation is outside the engine. Pimp uses default adaptive construction, minimum 22 true nonlands; better complete inputs may be retained. Multiplayer refuses a context snapshot differing from its session before committing; unavailable configured context does not silently downgrade.
